# Sorting

The classic comparison-based sorting algorithms, each demonstrating a
different strategy (divide-and-conquer, in-place swapping, heap-based).

| File | Algorithm | Time (avg) | Time (worst) | Space |
|---|---|---|---|---|
| [`bubbleSort.js`](bubbleSort.js) | Bubble Sort | O(n²) | O(n²) | O(1) |
| [`insertionSort.js`](insertionSort.js) | Insertion Sort | O(n²) | O(n²) | O(1) |
| [`selectionSort.js`](selectionSort.js) | Selection Sort | O(n²) | O(n²) | O(1) |
| [`mergeSort.js`](mergeSort.js) | Merge Sort | O(n log n) | O(n log n) | O(n) |
| [`quickSort.js`](quickSort.js) | Quick Sort (Hoare partition) | O(n log n) | O(n²) | O(log n) |
| [`quick_Sort_2n_Sol.js`](quick_Sort_2n_Sol.js) | Quick Sort (Lomuto-style, extra arrays) | O(n log n) | O(n²) | O(n) |
| [`heapSort.js`](heapSort.js) | Heap Sort | O(n log n) | O(n log n) | O(1) |
