# Linked List

A minimal singly linked list (`LinkedList`/`ListNode`) plus three classic
interview operations, all in [`linkedList.js`](linkedList.js):

| Function | Problem | Time | Space |
|---|---|---|---|
| `reverseList` | Reverse the list in place | O(n) | O(1) |
| `hasCycle` | Detect a cycle (Floyd's tortoise and hare) | O(n) | O(1) |
| `findMiddle` | Find the middle node (fast/slow pointers) | O(n) | O(1) |
