# Dynamic Programming

Problems solved by breaking them into overlapping subproblems and caching
the results (memoization or bottom-up tables).

| File | Problem | Time | Space |
|---|---|---|---|
| [`climbing_stairs.js`](climbing_stairs.js) | Count distinct ways to climb n stairs, 1 or 2 steps at a time | O(n) | O(n) |
| [`coin_change.js`](coin_change.js) | Fewest coins needed to make a target amount | O(amount × coins) | O(amount) |
| [`combination_sum_v4.js`](combination_sum_v4.js) | Count ordered combinations of numbers that sum to a target | O(target × n) | O(target) |
| [`house_robber.js`](house_robber.js) | Max money robbed from houses without robbing two adjacent ones | O(n) | O(n) |
| [`knapsack_01.js`](knapsack_01.js) | Max value under a weight cap, each item used at most once | O(n × capacity) | O(n × capacity) |
| [`longest_common_subsequence.js`](longest_common_subsequence.js) | Longest subsequence common to two strings | O(m × n) | O(m × n) |
| [`longest_increasing_subsequence.js`](longest_increasing_subsequence.js) | Length of the longest strictly increasing subsequence | O(n²) | O(n) |
